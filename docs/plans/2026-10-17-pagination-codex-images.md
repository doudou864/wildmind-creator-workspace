# 分页补齐与套餐生图验证

按用户已确认顺序执行，不新增依赖、不使用图像 API。

1. B站在真实稿件选择框按每批最多10条导出；逐批核对选择与CSV身份。小红书逐页读取列表并在对应页进入到期详情；YouTube逐页核对内容总数。拒绝重复页、缺行或分页未推进，避免假成功。
2. 配置近期作品容量与提前提醒阈值。容量提醒独立于登录/风控，不阻止正常定时采集；data:show 展示。测试跨页、跨批、未推进、提醒共存与阈值解除。
3. 三平台真实运行，核对符合起号日及30天规则的数量；记录真实覆盖与样本限制。格式化、全量检查、提交并push。
4. 在本机 ChatGPT 登录的 Codex CLI / SDK 实际生成图片，依次验证编辑/参考图、比例、文件落地及耗时。若不可用，记录证据并停止，不转API。
5. 可用才实现第8步：现有AI层、配置驱动、串行/每日额度、素材库共用、中文失败、无半成品；界面验收后继续9、10，到E停下。
