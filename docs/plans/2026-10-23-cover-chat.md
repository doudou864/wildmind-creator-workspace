# 视频封面直接对话实施计划

按用户本轮明确要求执行，不增加确认步骤。

目标：视频封面不要求选题/作品；左侧唯一原文输入与本机技能单选；右侧展示本轮返回的原比例图片，支持继续对话及刷新恢复。

实现：复用 src/ai/image-chat.ts 与 src/lib/image-chat-store.ts；加独立会话表，不创建虚假作品、不改变旧作品对话。技能从 config 指定的本机目录发现并在发送前验证，单独传递完整技能正文；用户消息保持独立原文。视频封面使用独立组件，其他用途保持现状。新增表前备份数据库并通过 Drizzle 迁移。

验收：临时数据库测试原文/技能/续聊/幂等/失败/图片原尺寸；隔离页面验证发送与刷新、两档 Ego 截图；npm run format、npm run check、构建。用标记的 fixture 实测 SDK，不使用真实作品与候选。新增依赖零项。
