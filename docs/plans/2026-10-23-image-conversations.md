# 生图中心聊天工作区实施计划

以用户最新截图与明确布局为准，替换上一版分用途/左右结果栏。

目标：左侧新建、搜索、切换、重命名、归档/恢复；中间按轮显示原文、Codex回复与原图；底部输入框左上比例快捷选择，右上技能选择。

1. 扩展独立会话表的标题与归档字段，增加每轮比例；迁移前在线备份。查询兼容旧会话及失败前未建立线程的历史，不删旧图/消息。
2. 增加会话列表/管理接口；从配置校验比例；比例独立送入SDK，正文保持原文；同一session继续原线程。
3. 替换生图页面并移除素材步骤的旧关联外壳；全站导航保留。各会话草稿在本机独立保存，切换时隔离延迟响应；生成期间仍可新建或查看其他会话。
4. 临时数据库测试新建/历史/重命名/归档/恢复/会话隔离/比例契约；隔离浏览器验证多会话草稿、延迟返回、图片与布局；1440/1728截图，完整check与构建。真实历史只读，不触发真实生图或修改真实会话。
