# 排版中心实施计划

目标：按 PRD 6.4 完成第四个业务前端；沿用用户确认的“前端与服务接口，未接入操作不可用”范围。

架构：本页识别显式文本结构，生成独立的公众号、抖音、X 三份稿件。配置控制风格、比例、图数；真实素材与历史稿件走服务读取器。持久化、AI、确认及发布交接只通过接口，不模拟成功。

技术：现有 Next.js / React / TypeScript / YAML / Zod，不新增依赖。

1. 新增 `config/layout-styles.yaml`、`src/lib/layout-model.ts` 和配置读取器，定义块结构、平台版本、修订号及操作校验。
2. 新增 `/layouts` 与 `src/ui/layout-preview.tsx`、`src/ui/layouts.css`：来源输入、三版并排、块编辑/排序、素材选择、分平台预览、离页保护。
3. 新增 GET/POST `/api/layouts`、PATCH `/api/layouts/:id`、POST `/api/layouts/:id/actions`。修改接口严格校验后返回 503。保存成功后才可确认，确认后才可交接，送出稿锁定。
4. 用原生 Node 断言测试结构转换、独立编辑、封面比例、图数、修订与确认边界。浏览器验证实际编辑、预览、空态、不可用状态与离页保护；1440/1728 截图；类型检查与构建。
5. 更新 README、接入契约和验收记录，提交 git。

边界：纯文本或 Markdown 标记识别不冒充 AI 理解；抖音初稿完整复用来源，由用户精简（AI 待接入）。默认图数 9 是可调整的工作台保守配置，非已核验的平台硬上限。预览呈现平台结构，平台端最终渲染仍需真实发布适配器验收。
