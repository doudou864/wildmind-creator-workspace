# 消息页按平台与作品组织（2026-10-21）

用户要求：去掉“有价值消息待回复 / 全部待回复会话评论 / 可送入选题 / 待识别失败 / 已归档”统计分类条和常驻评论详情；平台板块纵向排列，每个平台里放“作品标题 + 未回复评论数量”的长方形卡片，点击在右侧展示该作品评论。账号名加底色，与正文分开。

实施：复用现有消息读取、价值分类、回复判定和处理接口，只改展示。默认仍为待回复的有价值消息；私信单独成卡，不丢入口。归档、其他消息、待核对、搜索和主题放进折叠筛选，旧 URL 的 message/category/channel/reply/theme 参数继续生效。抽屉替代常驻详情，保留回复、撤销、草稿、选题和商单操作；账号名使用无边框浅底文字，不伪装成按钮。默认不打开抽屉，用户点击作品再打开；带 message 的原消息链接直接打开。

分组优先平台作品 ID，其次本地作品 ID。历史记录缺少两种 ID 时，仅按已采集的原始作品标题原样分组展示，不模糊匹配、不推断或写入作品关联；完全没有标题的进入“未关联作品的评论”。私信数量继续按会话去重，不用消息条数替代。历史同名且缺 ID 的源记录可能混在一个展示组，需以后采集明确 ID 才能可靠区分。

验收：1440/1728 真实页面只读截图；隔离 fixture 验证点击、归档/撤销、键盘关闭；分组与计数测试；全量检查与推送。不操作真实消息、不改数据库。
