# 视频创作主线 UI（2026-10-30 用户确认）

目标：六个独立一级入口，按需带入内容；保留暖灰、黑白与橙色。只隐藏非视频日常入口，旧地址、编辑功能、草稿与历史数据保留。不新增视频项目系统、依赖或数据库表。

1. 导航精简：总控台、消息、作品数据、选题、封面生成、一键发布；移除现代页面的创作子导航和拦截。旧创作地址保留参数转至相应独立页，旧排版/图文语义不变。
2. 流程衔接：选题进入独立封面草稿，不覆盖对话、不自动发送；图片明确选择新建或现有可编辑发布草稿，比例校验、替换确认；作品按真实 ID 直达评论；沿用评论送选题。
3. 页面减负：紧凑采集横栏；选题页头主操作、完成明细折叠；消息常用筛选可见；作品默认最近发布记录；发布表单首屏、任务下置且详情点击展开。

交接只应用一次，失效来源明确报错；保护已有编辑与旧历史，不按标题推断关联。采集、分析、回复判定和发布状态语义不变，遵守 collection-contract.md。

验收：纯逻辑测试覆盖交接、比例、草稿保护、真实 ID 筛选与兼容路由；真实组件使用隔离 fixture 模拟请求，在 1440×900 和 1728×1117 截图检查主操作、滚动和键盘焦点。禁止用真实作品上传/发布或处理真实消息。每批 format、npm run check 后提交并更新 ROADMAP。
