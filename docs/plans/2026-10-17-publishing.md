# 发布中心前端实施计划

目标：落实 PRD 6.5 / 第 13 章第 10 步的前端准备流程。继续用户批准的“前端与服务接口”范围，不新增依赖，不实现真实上传/数据库/AI/平台发布。

设计：视频、排版确认稿、小红书图文三个入口；左侧来源，中间平台模板，右侧核对清单，底部批次与回执。确认稿内容只读，调整内容必须退回排版。平台、比例和模板从配置读取；没有观看时段数据时不生成虚假的推荐时间。普通前端编辑与本机预览可用；未接入写操作禁用。

1. `config/publishing-templates.yaml`、`src/lib/publishing-model.ts` / config：模板、来源、版本化批次、回执状态、缺图与发布前置条件。
2. `src/app/publishing/`、`src/ui/publishing.css`：三入口、真实来源空态、本机文件预览、作品封面自动匹配、平台配置与人工确认清单、不可变确认稿与回执。
3. `/api/publishing` GET、drafts POST/PATCH、media POST、批次发布/AI/退回与单条回执重试接口。合法请求返回 503，不伪造成功。
4. 原生断言验证业务边界；浏览器检查本地操作、错误与状态隔离、1440/1728 截图；类型检查和生产构建。
5. 更新接入契约、README、验收记录，提交 git。

假设：比例映射为可调整的工作台默认模板，接入平台时再核验。尚无可靠的平台限制与观看分布，不填写猜测的标题硬上限或最佳时间；模板字段以 null 表示未核验，在发布校验中阻断。未开发的真实平台发布不因本页面存在而开放。
