A. 回复状态（改 PRD 389：允许手动标记，手动标记优先）
1. 每条消息有三种处理：「去回复」「不用回（低价值）」「标为已回复」。
2. 点「去回复」时依次做三件事：打开平台页面；把这条消息标为“已回复”并归档；把对方名字和评论前 20 字复制到剪贴板。页面底部弹出“已标记为已回复 · 撤销”，持续 10 秒；归档列表里也能撤销。
3. 跳转位置：逐个平台实测能否直接打开“这条评论所在作品”的评论管理页（作品 ID 拼进地址）。能做到的就直达；做不到的打开评论管理首页，并提示“在《作品名》下找 @某某”。每个平台实测了什么、结果如何，写进 README，不能写没验证过的地址。私信同理，没有的入口不要编。
4. 已回复和低价值的消息都进“已归档”，默认不显示，总控台、收件箱的待回复数字都不算它们。
5. 重新打开规则：归档后，如果平台读到同一个会话里对方又发了新消息，自动回到待回复，并标注“有新消息”。
6. 只记录用户手动标的“低价值”，暂时不拿去改分类规则；README 里写一份以后怎么用的方案。
7. 测试：标记、撤销、新消息重新打开、数字变化。用测试数据测，不动真实消息。

B. 发布：本机路径和删除
1. config 加一项“成片文件夹”（可以配多个），只允许读这些目录。选视频时列出文件夹里最新的视频（名称、时长、大小、修改时间），点一下选中；也能手动粘贴文件夹内的绝对路径。
2. 不再复制到 data/videos/，只记住路径和指纹（大小、修改时间、哈希）。上传前重新核对指纹，文件变了或不见了就拦下并说明。已经复制过的旧视频保持不动，在 README 写清以后怎么清理（不自动删）。
3. 删除和替换按阶段分三种：
   - 还没上传到平台：可以删除或换一个文件。
   - 已上传到平台、还没发布：可以“放弃这次上传”（只改本地记录，保留回执，可追溯），同时给出平台的草稿或作品管理页链接，提示去平台删除；不自动操作平台。
   - 已发布：不能删，只给“去平台管理”的链接。
   每种按钮旁边写清会发生什么。
4. 图片（小红书图文）同样支持移除或替换。
5. 不做真实上传，用测试数据验证。

C. 排版改成自由文档
1. 公众号做主稿：一个像 Word 或公众号后台那样的编辑区。可以随便写标题和段落，插入图片（从素材库选或直接上传），拖动调整图片大小，支持撤销和重做。没有固定的段落格子。
2. 现有的段落数据迁移成文档格式，不丢内容；确认稿快照的规则不变（确认后定格，发布只用快照）。
3. 「复制到公众号」：复制带样式的 HTML。实测粘贴进公众号后台后格式基本不乱，把实测结果写进 README（如果没有登录条件实测，就写明还没验证）。
4. 抖音图文和 X：从主稿一键生成各自版本，之后各改各的；标签上标明“和主稿不同步”。
5. 排版样式（layout-styles.yaml）作为可选主题保留，默认不强加。
