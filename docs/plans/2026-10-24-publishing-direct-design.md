# 视频发布页接通完整流程

依据用户 2026-10-24 明确要求：保留四项输入、平台选择、独立任务。上传只准备并停住；发布已上传的版本；新草稿直接发布则一次完成上传与发布。本次点击就是本批授权，覆盖旧流程必须上传后再确认的限制，不重复弹确认。

沿用现有浏览器适配器、后台进程与回执，不新增执行系统或依赖。与另建一个代理会话或依赖当前聊天相比，复用任务能保留暂停/恢复、页面与查重证据。

新增严格的 upload-and-publish 请求，要求 confirmed=true，校验保存版本和材料。持久保存原始授权、素材指纹、平台与适配文案；上传完成后只把已就绪项交给既有提交器，同进程原子切换阶段。普通上传没有授权，永不自动提交。已提交跳过，submitting/unknown 仅查回执；个别平台失败不阻断其他平台。恢复时继续未完成阶段，不扩大目标或重发。

首屏提供上传（描边）和发布（主按钮）。填完新草稿两者均可点；审核完成点发布直接用原页面。任务显示阶段，成功/平台审核中/待处理分别展示。

验收：隔离数据库和浏览器假页面验证两种入口、授权/版本约束、暂停恢复和未知回执不重复提交；真实 UI 在 1440/1728 截图。npm run check 全绿后提交。无新的测试作品，本轮不重复上传或发布旧视频，自动全链路的实站验收留给下一条用户作品。
