# 选题 Skill 驱动 Implementation Plan

**Goal:** 页面直接编辑用户指定的全局选题 Skill，下一轮按保存版本自主研究并交付实体与角度，旧业务规则配置退出运行入口。

**Architecture:** Skill 及其 Markdown 引用是唯一编辑规则来源；启动时快照。Agent 通过结构化动作提出搜索/读页或交付，宿主在统一 browser 层执行，只校验协议、引用、预算和保存。复用持久任务、SQLite 和历史状态，不迁移数据库、不新增依赖。

**Tech Stack:** TypeScript / Next.js / Codex SDK / Zod / ego / Vitest。

用户已授权实施。直接维护原 Skill；旧配置文件保留供历史追溯但不参与新任务。引用资料在同一编辑器可见。全局文件改写先备份；测试使用临时 Skill、临时数据库和显式 fixture，不占用真实候选。

1. 实现 Skill 读取、引用加载、版本冲突检查、备份及保存接口；启动快照绑定任务，缺失不回退旧规则。
2. 实现 Agent 的读页/搜索/交付循环；选择依据完全由 Skill 决定，宿主浏览器协议、停止、引用校验与原子保存保持确定性。
3. 页面撤下渠道编辑器，增加 Skill 查看编辑与版本状态，按钮改为找选题，候选分开呈现实体和角度。保留历史筛选和状态。
4. 定向测试：保存后下一轮规则变化、引用同步、冲突不覆盖、旧规则未注入、真实引用校验、异常保留材料、后台入口。
5. 隔离页面验证编辑保存/冲突/刷新/启动版本、两档截图；隔离实调模型验证新规则影响输出；全量 check、format、类型和构建检查。提交后更新 ROADMAP 与验收边界。
