# U9 C：自由文档排版

公众号主稿改为连续的文档编辑区，支持空白起稿、粘贴文章、标题和正文、加粗、小标题、列表、引用、素材库插图、直接上传图片、拖动缩放、撤销和重做。平台标签一次展示一版，抖音和 X 可从主稿生成，之后各改各的。主题默认不加，配置的正文主题仍可选。

## 选型与数据保留

采用用户批准的 TipTap 开源编辑器及配套 @tiptap/react、@tiptap/pm、@tiptap/starter-kit、@tiptap/extension-image；图片缩放使用官方 Image 自带能力，无额外缩放插件。适配现有 React/Next，`immediatelyRender:false` 避免服务端 hydration 差异。参考 [官方 React 文档](https://tiptap.dev/docs/editor/getting-started/install/react) 和 [Image 文档](https://tiptap.dev/docs/editor/extensions/nodes/image)。

旧 blocks 读取时无损转换为文档，文字、列表、引用、图片 ID 和图片说明保留；首次编辑后把文档和兼容 blocks 一起存进已有 JSON 字段。无需改表。没有批量改写旧确认稿。新确认稿保存完整文档；退回修改也不改已经留下的快照正文。平台之间没有自动同步。

## 四问

| 自查 | 结果 |
|---|---|
| 3 秒能看出要做什么 | 编辑正文为主区域，首屏保留当前平台确认按钮和缺项；不用理解段落编号。 |
| 可点与不可点 | 工具栏按钮、淡色禁用及原因清楚；图片角落拖拽柄可见。 |
| 无关或难懂文字 | 删除固定段落格子和编号；保留平台独立修改、手动发布及缺封面的必要说明。 |
| 数字一致 | 不改统计口径，图片引用来自同一文档；确认前仍使用原比例/数量规则。 |
