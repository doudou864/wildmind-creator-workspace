# U9 B：本机成片和分阶段移除

新视频只登记白名单内的原路径和大小、修改时间、SHA-256；不复制到 data/videos。选择器列出最新 20 个文件（可配置），显示时长、大小和修改时间，支持绝对路径。上传请求重新核对指纹；目录外、符号链接逃逸、文件变化或缺失都拒绝。

未上传可以移除本次关联或换文件；小红书配图也可移除、替换。已上传未发布可放弃本地批次，原状态和回执保留；已发布只给平台管理入口。未知结果和执行中的记录仍禁止替换、放弃、重发。没有删除任何真实文件或记录。

## 实测与边界

- `scripts/verify-u9-local-videos.mjs`：临时生成 1 秒测试 MP4，真实 ffprobe 读取、指纹登记、重复选择去重、修改后拒绝。结果见 [local-video-proof.json](local-video-proof.json)。临时数据库中的作品显式 fixture。
- Vitest：白名单、符号链接逃逸、改动/丢失文件；临时 fixture 批次放弃后回执逐字段不变；已发布/未知/执行中不能编辑。
- Ego 实际操作隔离页面：选择测试视频、移除选择、放弃上传。回执仍保留。页面复用真实组件，网络写入替换为内存 fixture；并非真实 API 上传验收。
- 已重启本机服务，`/publishing` HTTP 200。`npm run format` 和 `npm run check` 通过：46 个测试文件、109 项测试，原有检查全部通过。
- 用户尚未提供成片文件夹，`config/media.yaml` 的 `finishedVideoDirectories` 暂为空。实际文件夹的大文件读取速度、真实浏览器播放尚未验收。截图中的播放失败来自隔离页面没有提供视频接口。
- 真实上传服务仍未启用，上传前校验分支已接入，未执行真实上传/发布；E/F 安全规则保留。

## 平台管理入口

本轮点击 B 站「内容管理」实际到达 `https://member.bilibili.com/platform/upload-manager/article`，显示视频/稿件管理。抖音和 YouTube 复用现有采集配置中的作品管理入口。小红书创作者后台需要短信登录、视频号需要微信登录，本轮未验证深层管理页，只提供已知后台首页。未自动删除平台草稿。
