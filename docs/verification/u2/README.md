## Ego 真实使用与四问

模拟 11 点打开：先处理小红书商单。点击第一行进入 `/inbox?category=deal&reply=waiting&message=…`，看到该商单原消息；点击近期作品进入对应 `/data-center?post=…`。

| 自查 | 结果 |
|---|---|
| 3 秒内看出最要紧的事？ | 通过。首块大字今日行动，首行为商单待回复，主操作直接进入。 |
| 能点和不能点可分？ | 通过。操作为实底/描边按钮，导航行无框带箭头，状态为文字；重抓无接口所以禁用并解释。 |
| 还有无关字？ | 通过。去掉 A/B/C/D 和同步窗口，失败原因默认用大白话，详细错误需主动展开。 |
| 数字对得上？ | 通过。共享读取统计为商单 1、价值私信 2、价值评论 8；33 为证据不全而非待回复。近期作品 5 条，累计值来自最新保存点；数据中心同龄图使用日龄采样，U4 会明确区分名称和采样时间。 |

## design 第 10 节

一个主操作；单行页头；卡片无编号/英文装饰；过期数据明示日期和迟延；全空检查点列隐藏；不足 7 天不画趋势；空块折为一行；没有新增名称过滤。数据健康保留各平台过期信息，全部成功时收起。

`npm run format`、`npm run check` 全绿（99 项测试及现有集成检查）。没有真实上传、发布或合并数据。手动重抓缺少现有接口的限制记录在 [u-questions](../../plans/u-questions.md)。
