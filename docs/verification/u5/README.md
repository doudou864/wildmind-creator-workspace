## Ego 实际任务与四问

选择唯一候选“用华容道检查AI：答案能不能逐步复现”（3c1b569f…），点击选中后进入已选视图，卡片“去做图”跳到生图页，选题自动选择正确。真实选择已保留：候选 0、已选中 1、已跳过 19、已发布 7，总数仍 27。没有生成新候选或删除记录。

| 问题 | 结果 |
|---|---|
| 三秒内看出任务？ | 通过。列表在左侧主区，候选不足时直接提示生成下一批；有候选时可直接选中。 |
| 操作与标签可分？ | 通过。选中/跳过为按钮，探索和已选状态为无框文字，跳转带箭头。 |
| 有无无关字？ | 通过。无 ISO 时间、history 内部字段、编号或英文装饰；原始依据保留并用正常日期表达。 |
| 数字对齐？ | 通过。27 条来源与各状态合计一致；探索数按当前筛选范围显示，不和全库数混用。 |

对照 design 第 10 节：单主区域、单刷新、低库存一个实底主按钮、无默认大空块。主按钮按本段要求放列表顶部（与页头很近，在首屏），不在页头重复。未改生成量、FIRE 规则、状态定义、接口或数据库结构。没有结构化热度验证证据，统一注明热度未验证，不把关键词占比冒充全网热度。

npm run format / npm run check 全绿（99 项测试及既有检查）。继续 U6。
