# 视频页上传与直接发布 · 2026-10-24

按用户本轮要求接通三条路径：上传后停审；审核后发布原上传；新草稿直接发布一次完成上传与提交。沿用五个平台适配器（抖音、小红书、B站、视频号、YouTube）、独立任务、暂停/恢复/删除。

## 已验证

- 新的严格请求须 confirmed=true、保存版本与材料匹配、平台与当前选择一致。入队保存原始授权时间/材料、源视频 SHA-256；重复请求不重复启动进程。普通上传不会获得发布授权。
- 上传 worker 同进程转入提交，保留 token 与进程所有权。准备阶段暂停/删除或旧 token 不得转入发布。源文件变动停止上传/直接发布。
- 隔离数据库与浏览器桩执行真实 worker：普通上传停 ready 并交回浏览器；直接发布提交已就绪平台；逐平台 submitting 在点击前落盘，成功项恢复不再点击。某平台失败不阻断其余就绪项；任务保持 attention，下一次继续未完成上传阶段。全批明确提交后关闭自己的工作区；清理失败保留原因与浏览器记录。
- Ego 空间64访问仅本机隔离 fixture（无平台请求），实际点击新草稿“发布”产生 upload-and-publish / confirmed=true；“上传”产生 upload / confirmed=false 并停待审，再点击“发布”产生 publish-all / confirmed=true。真实 /publishing 页面只读确认两按钮已出现，HTTP200。
- [1440截图](1440.png)、[1728截图](1728.png)：viewport/scrollWidth分别为1440/1728，截图高度1000，主操作在900首屏以内。暖灰/黑白变量、共用按钮组件，发布唯一实底主操作，表单无横向溢出。平台审核中不再冒充已公开。
- npm run format、npm run check 全部通过：78个测试文件、208项测试（包含本次11项直接发布回归）；36项发布业务检查通过，无跳过。已有 MODULE_TYPELESS_PACKAGE_JSON 性能提示不影响检查结果。

## 实测边界

本轮没有新的测试作品，未再次上传或发布已提交的《AI发展史》，未改真实回执。上轮各平台实站提交已验证，但部分步骤曾手动接管；本次接通的是页面授权与后台编排，不能据此宣称五平台全链路无人接管已实测。下一条用户作品才用于新流程实站验收。登录验证、事实声明缺项或平台变化会保留原因并要求处理，不猜声明或伪造成功。

可运行 `node scripts/preview-publishing-simple.mjs docs/verification/publishing-direct` 重建隔离预览；`?stage=draft` 为已填写草稿，`?stage=ready` 为已上传草稿。生成HTML为本地验收临时文件，不纳入提交。
