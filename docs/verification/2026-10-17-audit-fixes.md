# 全站前端十项审查问题修复验收

范围：PRD v1.7 的七个现有板块，纯前端与服务接口。没有新增依赖、接入数据库、真实上传、调用 AI 或向平台发布。

## 问题对应

| 审查问题 | 修复结果 | 验收 |
|---|---|---|
| 缺少作品关联主线 | Content 定义、只读/创建接口、四页共用选择创建入口；一个选题多作品，排版稿与发布携带 contentId | 隔离接口中新建图文作品，排版保存载荷使用同一 ID；不同形式不混选 |
| 浏览器后退丢编辑 | 当前浏览器文档内存保留临时编辑，返回恢复；明确放弃/成功保存清除，刷新关闭提醒 | 排版、生图、发布、商单四页均实测后退返回恢复 |
| 保存过程中新增编辑被误标保存 | 生图提交快照与后续编辑版本分开；本地文件预览不随文字保存清除未保存标记 | 延迟保存 A，过程中编辑 B；提交仍 A，页面 B 且 dirty=true |
| 确认内容随封面变化漂移 | 作品采用明确封面版本；发布确认材料指纹，变化即使当前确认失效；请求要求材料指纹 | 更换采用封面后旧清单显示重新核对并阻断；默认 selected 改变不替换已采用封面 |
| 多封面组冲突无解除路径 | 按作品/比例指定采用版本或解除，独立于 family 内默认选版 | 浏览器采用 assetId，解除传 null；请求分别携带作品修订号 1、2 |
| 上传来源与用途混用 | 上传选择实际用途；元数据用途/关联编辑接口；旧上传图可进入单图修改 | 手工视频封面可采用；旧 upload 素材填写要求后修改版按钮可用 |
| 生图与排版抖音比例冲突 | reuseAnyRatio 仅配置给允许任意比例的用途，抖音按真实尺寸检查 | 16:9 图不能复用为 3:4 抖音配图；普通文章插图仍可保留原比例 |
| 总控台缺少跨板块待办 | 问题、计划、需求主题、账号异常 DTO、展示与深链接；来源就绪状态独立 | 同屏显示一会话、一个问题、一个计划、一个异常=4行动；主题可定位来源；未接入不显示假零待办 |
| 同会话待办重复 | 按平台+会话聚合，保留组内全部商单入口；评论独立计数 | 两条同会话商单计一个沟通行动，跨平台同会话 ID 不合并 |
| 平台内容形式不一致 | 小红书、视频号配置加入图文 | 配置规则回归通过 |

## 接入边界

所有新写接口仍是显式不可用边界，保存/采用/同步的成功路径由隔离契约回执验证。真实服务接入时仍需实现文档中的事务、关系校验、文件解码、材料指纹核对与幂等要求，不代表已经具有实际持久化或平台发布能力。

临时恢复仅限当前窗口站内导航，未保存内容不会跨整页刷新或关闭窗口持久化。平台真实预览和发布端验证继续留待发布服务接入。
