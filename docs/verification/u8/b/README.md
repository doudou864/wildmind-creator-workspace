## 改动与真实只读核对

- 趋势来自已存完整日 account_daily，写「趋势统计到 10-17」；健康来自 crawl_logs 最近成功结束时间，写「数据停在 10-18（晚 2 天）」。这是数据所属日期与读取日期的区别，不再混用同一种标签。近期作品的读取日期集中放区块标题，行内不重复，失败之外不强调过期。
- 删除所有禁用重抓按钮，底部说明项目终端 npm run collect。没有执行采集。空的粉丝净增格隐藏，趋势/粉丝并排小卡。两个门槛分别叫命中率 / 历史推荐。
- 收件箱默认筛选与需求主题折叠；移除左侧重复分类，分类选项保留在筛选里。回复入口只在选中消息和详情出现。详情 sticky：页面滚动 700px 后 top=12px，右侧仍可见。
- 本条数据前置四个关键指标，其他按留存、互动、流量来源、粉丝折叠。单位跟随数值，指标表最大宽度保持 960px。
- 重复互动指标保留「量」及原有自算每千播放值，折叠对应平台率（点赞、评论、收藏、分享、涨粉），因为它们对应同一事件，且量提供直接可读次数；次数缺失则保留平台率。映射明确列在 config/data-center.yaml，不靠关键词猜记录含义。原始平台率仍留在数据、原算法和 AI 输入中。
- 示例 D3：播放 1,172 次，点赞 26 次 · 每千播放 22.18，涨粉 2 人 · 每千播放 1.71。真实次数直接读取 comparison.capturedAt 对应的原始采集行，不从比例反推。最新累计播放 1,510 是另一个采样时刻，名称明确区分。
