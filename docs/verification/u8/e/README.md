## 横版失败原因

[原始请求、调用 ID、尺寸和文件哈希](ratio-proof.json)：传入 2.35:1 正确，生成器返回 1920×819。现有严格整数比例规则需要裁到 1880×800，宽损失 2.0833%、高损失 2.3199%，超过 2% 限制。保留拒绝结果，未裁剪、补边、拉伸或放宽校验；补了回归测试防止静默放宽。

若要救回原图，补边至 1927×820 或单图批准 1880×800 裁剪均需用户决定；也可继续要求生成器给出严格尺寸，不合格拒绝。详见 [待决定清单](../../../plans/u-questions.md)。本轮未调用生成器。
