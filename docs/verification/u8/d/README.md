# U8 D · 创作外壳与四步骤

2026-10-20。/create 用 content 参数保留作品，顶部固定显示作品与形式，一次只展开选题 / 素材 / 排版 / 发布检查之一；视频没有排版入口，直接请求视频的排版步骤也回到素材。旧页面继续可用。

## 调整

- 候选为零只显示用完提示、生成和继续已选入口；不出现零数量筛选或空依据卡。非空筛选的来源名称明确为本范围来源。
- 素材设置在按钮前；去掉重复输出比例，按明确 contentId 默认筛当前作品素材，搜索不填作品名、不自动聚焦；新建任务改为清空要求，另做一张。去掉素材工作区固定的大空高度。
- 排版平台标签单选、带缺项和手动发布提示；文本框随内容增高。当前平台确认操作在首屏，不存在确认稿时没有准备发布入口；禁用按钮旁显示具体原因。确认仍经过原确认对话框与原 action，完成后带同一作品进入发布准备。
- 图文尚无任何确认快照时，发布页只有去排版确认卡片。已存在快照但不在 ready 状态的记录仍展示原安全状态，不误判成无确认稿。视频继续原材料检查。上传禁用时列明缺项。

## 真实浏览器操作与限制

Ego 打开 [独立 fixture 预览](fixture-preview.html)，切换 X 标签、输入 20 行测试文字、查看确认对话框后关闭，再沿步骤进入素材和发布检查。只有当前平台稿件，文本框自动增高；搜索为空且未聚焦，其他作品范围默认关闭。两档均无横向溢出。

预览由 scripts/preview-u8-fixtures.mjs 打包真实页面组件；数据逐条显式 fixture，只在这个隔离文件展示。预览拦截全部网络请求，写入/生成/上传均禁止，不连接数据库。确认只验证到对话框，未点击最终确认；真正确认快照的规则由既有后端测试验证。没有拿真实作品或消息执行这些动作。真实页面路由仅 HTTP 读取核对。

npm run format / npm run check 全绿：104 项测试及既有检查。已知问题：横版生成失败与 U6 真实数据遗留转 E 处理；平台真实上传、发布未验证也未执行；预览不代表真实 AI 生成/保存/上传通过。
