## 隔离交互验收

使用 `scripts/preview-video-workflow.mjs` 编译真实客户端组件。测试记录均标记为 fixture，数据仅存在预览页面的本机存储；请求由本地模拟层处理，未连接生产数据库或平台。样式包含现有 Tailwind preflight 与业务 CSS。

| 场景 | 实测结果 |
| --- | --- |
| 选题带入封面 | 新建独立本机对话草稿，带入可编辑文字；不发送生成请求，不提前创建作品；编辑后刷新仍是同一草稿 |
| 已有发布草稿 | 替换前必须明确确认；保存后主题、视频路径和其他比例封面保持原值 |
| 无效图片与比例 | 方形图片不冒充配置要求的封面比例；已失效图片显示原因且没有写请求 |
| 返回结果丢失 | 模拟服务已保存但响应未送达：仅一条草稿；刷新后待核对提示仍在，交接表单锁定，没有第二次写请求 |
| 继续已保存记录 | 从任务列表载入含该图片的记录并结束交接，只清理本机待核对标记、恢复该记录，不重发保存或发布请求 |
| 作品直达评论 | 用本地作品 ID 解析真实平台作品 ID；打开对应两条评论，同名另一作品的评论不会混入；范围可清除 |
| 空数据与读取失败 | 空消息显示明确空状态；刷新失败在页面显示错误，原主题和视频路径保留，无意外写请求 |
| 采集状态 | 运行中显示“采集中”和停止操作；注入旧错误不会覆盖当前执行状态；成功与平台数据日期滞后分开显示 |
| 选题运行结果 | 完成后网站明细折叠；失败原因、原候选和历史来源提示保留 |
| 多平台结果 | 未完成及结果待核对详情可点击展开；移开鼠标不会关闭；键盘 Enter 可展开，焦点可见 |
| 图片显示 | 3:4、4:3、16:9、1:1 的实际显示宽高与原图比例一致，object-fit 为 contain；正文可独立滚动，输入框保留 |

六页在 1440×900 和 1728×1117 共 12 张截图逐一查看：导航均为六项，未发现横向溢出或客户端运行错误；主操作、刷新入口和长标题可见。消息高级筛选支持键盘展开且焦点可见。

作品页的有数据截图使用共享图表和入口组件的隔离演示，不代表重新验收现有完整分析算法；默认作品及精确筛选由针对性测试覆盖。

另以独立空数据库运行真实 Next 页面：六页完成客户端加载，页面标题、浏览器标题与当前一级入口一致；失效选题明确提示；旧创作的素材入口保留选题参数转到封面页，旧排版地址仍可访问，旧图文发布保留原类型；无效作品参数返回 404 页面。验收前后 36 张业务表均为空，写请求为 0。曾遇到测试代理未转发 Next 开发连接而等待加载，修复临时代理后通过，业务代码无需为此修改。
