## 实际任务

Ego 从总控台点击首条商单，进入该消息；点击复制名字后按钮显示“已复制名字”；点击“去平台回复 ↗”打开已登录的小红书消息管理页，实际列表中能看到“连尚云汉孵化中心”。没有发送消息。商单页默认打开这条合作线索，回复入口在详情开头。

## 四问与设计自查

| 问题 | 结果 |
|---|---|
| 三秒内知道先做什么？ | 通过。页头说明 11 条有价值消息待回复，其中商单 1 条，列表先显示商单。 |
| 可点和状态是否分清？ | 通过。消息行悬停加深并带箭头，状态无框；回复链接、复制按钮各有清楚用途。 |
| 有没有无关或看不懂的字？ | 通过。读取失败改成简短原因；回复证据主动展开；去掉后台入库流程说明。 |
| 数字能否对上？ | 通过。总控台与收件箱同用 inboxSummary，1+2+8=11；42 为全部待回复会话/评论，387 为已存消息，53 为可送入选题，名称区分。商单待处理 1、跟进中 0、已完成 0。 |

两档无横向溢出，页头只有一个刷新，默认详情不留空，导航不变；没有改变业务分类、回复状态推断、接口、数据库。回复地址来自 browser.yaml，原文 URL 优先；抖音无独立已核实 URL 时提示打开通知/消息。

`npm run format` 与 `npm run check` 全绿（99 项测试及既有检查）。浏览器操作中一次误用 TaskSpace.snapshot，随后改用已有 page.snapshot 核实平台页面，不影响页面功能。继续 U4。
