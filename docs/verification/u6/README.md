# U6 生图、排版、发布

2026-10-20。三页共用 ContentPicker，链接带着作品；生图去任务名输入、自动命名，生成按钮紧跟画面要求，素材放中间标签页，图片详情改抽屉，“改这张”放在图上。排版恢复最近未确认稿，空白时只有文章输入与开始按钮。发布先选材料、平台，再写文案和检查，文案旁显示配置中的字数限制；本机成片入口收起，缺项可跳到对应区域。

## Ego 连贯使用

1. 延续 U5 已选的华容道方向，创建一条图文作品 `c051b651…`，只选择/建立这一次作品。
2. 首次公众号横版生成比例不符合要求，被原有校验拒绝保存。没有放宽校验或自动重发；改用自由生图 1:1，成功生成 1254×1254 封面，选定该版。
3. 点“去排版”，作品已自动带入；粘贴明确标为“待验证制作草稿”的文章，开始排版后才出现三个版本。将方形图放进公众号转发卡片位置。
4. 点“准备发布”，仍是相同作品。未确认稿件，因此平台上传保持禁用，页头提示先回排版确认。没有触发真实上传或发布。
5. 单独打开排版页，默认恢复刚才的未确认稿；点新建时三版区域消失，点继续上次恢复三版，作品 ID 不变。

本次留下的内容是制作草稿，不是已审定成稿；横版头图、题面和实际验证结果仍需完成。新作品、方形图、排版稿保留，原图复制进本目录让云端可访问；数据库仍留本机。

## 四问

| 页面 | 三秒内看出任务 | 操作/状态分清 | 无无关文字 | 数字/关联一致 |
|---|---|---|---|---|
| 生图 | 通过：填画面要求，紧接生成 | 通过：生成按钮、图上修改、抽屉详情 | 通过：无任务名输入、默认灰框、开发参考规则 | 通过：素材 13→14，失败未保存；作品一致 |
| 排版 | 通过：先粘贴，已有稿继续编辑 | 通过：版本状态无框，确认操作仍明确 | 通过：未排版不放三个空面板 | 通过：同一作品、三份 draft，封面引用正确 |
| 发布 | 通过：没稿件时明确先确认稿件 | 通过：未满足条件上传禁用并解释 | 通过：去掉 00 个目标平台与空大块 | 通过：同一作品；缺项来自原验证器，没有另算口径 |

1440 / 1728 无横向溢出，每页仅一个刷新。1440 主操作位置：生图约 579px，排版/发布约 84px。卡片无编号/装饰英文；素材及草稿文字左对齐，长标题截断可悬停看全文。按钮不折行。只调整页面交互与展示。

## 验证与边界

`npm run format`、`npm run check` 全绿：101 项测试，以及原有 21 项收件箱、15 项排版、36 项发布等检查。新增测试保证：唯一成片才自动选中、多成片不猜；继续最近未确认稿时不串作品、不把全部已送出稿当待编辑。第一次新增测试使用了测试运行器不支持的路径别名，已改成项目惯用相对路径并重跑通过。

确认稿只读、过期校验、截图审核、未知结果禁止重发、上传与最终发布分离等判断和接口均未改。生图失败如实保留。未为这次 UI 演示放宽业务限制，未删除/合并数据。继续 U7，只出方案。
