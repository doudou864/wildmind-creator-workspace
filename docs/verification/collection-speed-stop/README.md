2026-10-21。代码与隔离验收完成；未拿真实业务数据运行覆盖/停止测试，没有真实上传、发布或删数据。

## 改了什么

- 抖音评论改走创作者中心 → 内容管理 → 搜索已建档作品 → 作品详情 → 评论管理；集中读取评论文本、点赞与回复，展开回复时核对作者标记。一条作品完整读取后才更新其评论；没有读到列表末尾则拒绝提交该作品的半份结果。分类仍用原规则，明确数字直接读取，不再为每条评论另开主页来识别互动数。
- B站、视频号、YouTube 原有适配器已经使用后台评论管理，保留。小红书创作者后台本次显示登录页，不能确认其管理入口，保留原有实现，不假称已改完。
- 每个平台可停止，全部平台也可停止；不会终止选题取材。后台每 500ms 检查停止请求，中止 AI 等待/浏览器客户端，入库前再次检查。已经发到浏览器的只读操作可能先完成，不能撤回平台请求。停止后保留已完成数据；当天定时器不再悄悄重启该平台，手动可重新启动，次日仍按计划。
- 再次手动启动清除旧列表/详情缓存引用，重新读取；原始证据文件不删。平台指标事务完整后更新，消息按作品/来源批次处理，不是所有平台同时回滚的大事务。因此指标采集完成、评论中途停止时，完整指标会保留。
- 作品数据以「作品 + 指标 + 北京时间采集日」更新当日行；账号数据继续按平台标注日期更新。旧库历史重复行不删除，读取时只使用同日最后一份；图表从“同日最早”改为“同日最后”。当天新值为未知则保持未知，不偷用旧数。检查点日龄、分位数公式、首次发布/选中定格不改，已经冻结的检查点及命中率不追溯重算。
