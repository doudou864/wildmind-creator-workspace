# 生图中心统一对话验收 · 2026-10-23

整个生图中心改为左侧对话历史、中央消息流、底部常驻输入框。旧用途页签、关联作品、模板和输出安排撤下。比例快捷项位于输入框左上，技能单选位于右上；提示词原文、比例和技能分别传递。支持新对话、搜索、重命名、归档和恢复；不删除旧素材。

- `npm run format`、`npm run check` 通过：74 个测试文件，185 项测试，另有全部脚本检查（含 36 项发布检查）。共享工作区同期有其他发布改动，185 是当次全库检查总数。
