# 排版中心前端验收 · 2026-10-17

范围：PRD 6.4 的前端与服务接口。沿用“不安装依赖，未接入操作显示不可用”的决定；不宣称持久化、AI、平台发布已完成。

## 已实现

- `/layouts` 接入顶栏。来源显式结构识别，三版并排、独立编辑标题/正文/结构/顺序/配图。
- 公众号完整结构与 2.35:1 / 1:1 双封面；抖音同源文本、配置比例/图数、前后翻图与横向滑动；X 引用转正文，保留标题/加粗/列表/图片。
- 素材选择按真实资产记录，限定封面/抖音比例；无素材显示空态并提供生图中心新窗口链接。
- 每版独立确认状态，修改撤销确认，送出版本锁定。操作经服务返回成功才更新，不做虚假乐观成功。
- 未保存新建、站内导航和页面关闭提醒；读取/保存/交接失败保留编辑。稿件库切换清除上一稿的 AI 修改要求。

## 验证结果

- 严格类型检查、生产构建通过；4 个页面和对应接口均在构建路由中。
- `scripts/check-layouts.mjs`：15 项通过，覆盖同源独立、结构保留、确认失效、锁定、比例与图数、缺失资产、严格输入与修订号。
- 既有 `scripts/check-business.mjs`：21 项通过。
- HTTP：11 项通过。GET 返回真实空记录及关闭的能力；合法写入返回 503；伪造状态、缺失版本号、空 AI 要求、非法 publish 动作返回 400。
- Ego 浏览器：12 项基础行为 + 11 项隔离状态检查 + 2 项段落排序检查通过。包括 HTML 文本不会执行、三版独立、未保存保护、封面筛选、服务失败、已送出锁定、翻图/滑动、测试隔离撤销。
- 1440px / 1728px 截图检查：三栏无横向溢出；只使用设计变量；橙色限当前导航；复用共享卡片/按钮/弹窗。编辑、空态和预览截图见 `layouts/`。

浏览器状态检查只在专用验收页临时替换 GET 数据，写操作仍命中真实 503 接口。验收结束已刷新移除临时数据，未向运行服务植入演示内容、未保存测试稿件。

开发服务曾缓存“新 CSS 文件尚不存在”错误；重新加载开发缓存后恢复。最终开发页面与生产构建均可用。没有更换构建工具或安装依赖。
