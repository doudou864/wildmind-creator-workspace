# 采集按钮误拦截修复（2026-10-21）

原因：Next 内部 request.url 使用 localhost，浏览器 Origin 使用 127.0.0.1，原来的字符串比较把正常本机请求拒绝为 403。

改成核对 Origin 与实际 Host，并限定 localhost/127.0.0.1/IPv6 回环地址。同源本机请求放行，外部来源、不同端口及缺少 Origin 仍拒绝。

真实运行服务验证（故意使用不存在的平台，不启动真实采集）：
- 修前本机请求返回 403“请从本机工作台启动采集”。
- 修后相同请求通过来源检查，返回 409“该平台不在采集配置中”。
- 外站 Origin 仍返回 403。

新增回归测试覆盖框架地址规范化和拒绝外站。没有改 UI，1440/1728 布局沿用 ../collection-strip/ 的截图。四问无视觉变更；按钮入口误拦截已修，统计不变。本轮没有拿真实账号执行采集，不能把入口验证称为采集成功。
