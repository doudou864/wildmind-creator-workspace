# 选题中心前端验收记录

范围：第二个前端页面 `/topics`。沿用已确认的先前端方式，不接真实 AI、采集或数据库。

## 已完成

- 总控台 / 选题中心共享顶部导航，可以互相跳转；其余板块保持禁用。
- 三栏页面：输入渠道与样本门槛、候选列表与筛选、来源与推荐依据 / 已选清单。
- 默认 20 条演示候选、3 个探索位、4 个带具体 D21 理由的 FIRE。
- 支持关键词、来源渠道、候选 / 已选 / 跳过、FIRE / 探索筛选。
- 选中、跳过、移回候选；首次选中的 FIRE 和理由定格；本浏览器持久化。
- 样本不足 / 无数据场景；无数据预览不删除演示记录。
- 读取 `config/选题输入渠道.md` 的 YAML 配置。内置渠道启用状态参与演示批次筛选；外部渠道提供可编辑模板。页面只查看文档，不假装写入文件或执行采集。

## 验证

- `npm run typecheck` 通过。
- `npm run build` 通过，包含 `/` 和 `/topics` 两条动态路由。
- Ego 26 项浏览器断言全部通过，详见 `topics-checks.json`。
- 检查覆盖：默认数量与标签、渠道/类型/搜索筛选、样本门槛、首次定格、移回再选、刷新恢复、跳过与恢复、来源文档、对话框焦点、无数据、两页导航、总控台三图八作品回归。
- 故障验证：损坏记录不被覆盖；取消重置保留原值；确认重置恢复；模拟保存失败时明确提示未落盘。测试后恢复测试前的专用演示存储键，没有清理其他浏览器数据。
- 独立配置与数据断言通过：20 个候选 / 3 个探索；每个 FIRE 理由含 D21 倍数；无理由的定格记录被拒绝；修改渠道启用状态可重新读取；重复渠道 ID、无效探索位范围被拒绝。
- 首轮截图碰到 Next.js 流式加载占位，增加“客户端记录恢复完成”的等待条件后重新截图，最终交付不是加载画面。
