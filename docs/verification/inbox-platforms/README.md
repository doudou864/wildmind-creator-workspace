# 消息页：平台 → 作品 → 评论（2026-10-21）

## 改动

- 删除顶部六项统计分类条、重复的视图名称、常驻单条消息详情和后续流转大卡。
- 平台纵向排列，平台内为作品长方形卡：原始作品标题、待回复数量、→。点击打开右侧抽屉，显示当前范围内该作品全部评论，不再被原消息分页切散。
- 默认仍看待回复的有价值消息。私信单独成卡；归档、其他消息、识别状态、搜索、需求主题收进折叠筛选，保留旧 URL 筛选/原消息链接。
- 账号名使用 @ 与浅底色、无边框，与评论正文明确分开。回复、低价值、标已回复、草稿、送进选题和商单入口就地保留。
- 复用原有 Dialog（关闭、Esc、焦点恢复），修正撤销提示在模态抽屉内可操作，避免被模态层挡住。

## 已知限制

部分历史评论没有平台作品 ID / 本地作品 ID，只保存源作品标题。按同平台完整源标题临时分组，仅用于呈现，不写作品关联。若历史源作品同名而无 ID，当前无法可靠区分；需后续采集明确身份解决。完全没有标题的记录保留“未关联作品的评论”入口。

归档筛选仍受“有价值 / 全部消息”范围限制；查看全部归档时将消息范围设为“全部消息”。没有重新引入顶部统计条。

Ego 提示有更新，本轮遵循用户此前要求未升级。
