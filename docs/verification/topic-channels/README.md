# 选题渠道面板（2026-10-21）

在选题面板常驻“选题渠道”，每条自定义渠道只有标题和链接。可以添加、修改并保存、删除，候选为空时也能使用。内置搜索词与收件箱来源不改动。

保存回 `config/选题输入渠道.md` 的原 YAML 区块，生成逻辑照旧每次读取这份配置。外部渠道默认启用；新增不打开浏览器、不自动生成候选。编辑保留渠道 ID 和原有其他字段，删除仅移除配置，不碰历史信号和选题。每次变更先备份原文到 `data/backups/topic-channels/`，带版本校验和写入锁，临时文件写完再替换。

## 实测

- Ego 隔离 fixture：填写标题和 https 链接 → 添加成功；修改两项 → 保存成功且 ID 不变；删除 → 列表恢复空，候选区域仍保留。
- 临时文件测试：真实保存与重新读取、修改、删除、内置渠道保护、文档前言保留、备份、陈旧版本拒绝、非 HTTP/HTTPS 和带账号密码链接拒绝。未增删真实渠道。
- `npm run check`：54 个测试文件、121 项测试全部通过；既有生成读取外部渠道测试也通过。未调用真实 AI 生成或打开新增来源网站，站点可访问性取决于用户实际填入的链接及登录状态。
- 生成规则、候选数量、分类和统计未改。未新增依赖或数据库字段。

## 四问自查

1. 3 秒能看懂：标题 + 链接 + 添加渠道，入口始终可见。
2. 能点与不能点：填写不全时添加禁用，已存条目有修改/删除按钮与来源跳转箭头。
3. 无关文字：不展示内部 ID、读取频率、类型、focus 等字段。
4. 数字一致：没有新增渠道计数条，不改变候选列表计数与生成规则。

隔离预览由 `scripts/preview-topic-channels.mjs` 生成，复用真实组件，存取由内存替身处理，不写真实配置。
