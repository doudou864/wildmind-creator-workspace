# 选题渠道左栏与生效验证（2026-10-21）

渠道移到左侧 320px 栏，右侧保留候选与依据。可连续“增加一行”，每行标题、链接直接编辑；保存行、空行都能删除。左栏长列表独立滚动。有未保存行时生成按钮禁用并提示保存/删除，避免输入尚未落盘就开始生成。

- 实际页面只读：[1440](panel-1440.png)、[1728](panel-1728.png)。

## 渠道不是展示空壳

增强集成测试 `src/lib/topic-store.test.ts`：通过面板相同的 editTopicChannel 保存标题和链接到临时配置文件 → loadTopicChannels 重新读取 → generateTopics 使用已保存渠道 → 断言浏览器读取器收到该渠道 → 生成 20 条候选落入临时数据库 → 断言所有候选 channelId 和 sourceUrl 指向刚保存的渠道。生成器、配置读写、信号和候选入库运行真实代码，浏览器页面内容及 AI 输出为替身。

生产调用链：POST /api/topics/channels 写回配置；POST /api/topics/generate 调用 generateTopics，默认每次 loadTopicChannels，再交给 readTopicSources 读取启用网址。网页读取失败会报错，本批不跳过失败来源假装完成。

`npm run check` 全绿：54 个文件、121 项测试。未调用用户真实渠道生成，也未实测任意网站登录/可读性；不能保证所有用户填写的网址都无需登录即可读取。

## 四问

- 任务清楚：左侧填渠道，右侧选方向。
- 操作清楚：增加一行、保存渠道、删除行；已保存为文字状态。
- 无内部字段：用户只填写标题和链接。
- 数字一致：保留已有候选与统计，测试确认新增渠道生成的 20 条候选均记录正确来源。
