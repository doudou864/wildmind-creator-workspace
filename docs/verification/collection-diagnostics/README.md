# 2026-10-28 采集诊断验收

## 事实与原因

数据库最近记录：10月28日19:41开始的一轮中，抖音19:58、B站19:52、YouTube19:44完成成功。截图的“今天未更新”来自页面首次渲染的 today 属性未随轮询更新；旧日期还把25日显示成晚1天。小红书最近执行仍为26日验证码失败，待处理状态持续阻挡定时采集。视频号28日19:41执行等待桌面微信允许；另有25日浏览器异常待处理。不能把这些状态归为今天全部采集失败。

此外，runCollection 在检查本次是否到执行时段前清空 last-error，导致启动错误可能被下一次空轮询抹掉。本次移动清除到确认有实际执行候选以后。此前浏览器错误仅保存通用翻译，无底层堆栈，无法追溯历史未知异常精确触发点；不会补造。

## 改动

- collection 状态接口返回北京时间当天日期与待处理记录。页面按最新日期判断、优先展示最新阻塞原因及日期，执行结束替换“已启动”旧提示。
- 每次 crawl UUID 对应数据库旁 execution-logs JSONL；在步骤开始即落盘。记录浏览器操作类别、AI模型与识别/判断、校验、登录和指标/互动阶段、时间、耗时、失败堆栈、底层错误摘要。日志不包含完整脚本、提示词或页面全文；错误中的凭据及URL查询参数脱敏。
- 网页每平台“执行日志”按需读取最近10次，展开结果、耗时、存档文件路径和步骤；刷新可读正在执行的记录，旧记录明示无步骤日志。日志目录权限0700、文件0600，无表结构修改。
