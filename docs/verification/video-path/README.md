# 本地路径流程纠正（2026-10-21）

用户先提供具体视频文件路径，系统再读取这一个视频。不先探索目录、推送新视频或让用户从扫描结果挑选。

## 改动

- 发布的本机入口直接显示“视频文件路径”和“读取这个视频”；页面加载、输入文字均不发读取请求，只有点击按钮后提交指定路径。
- 今天页取消“有新成片，要建作品吗？”及文件探测错误；采集健康提示保留。
- 删除目录枚举实现。旧 GET 列表接口保留空返回以兼容，今天页接口旧 newVideos/fileErrors 字段固定为空；都不读取视频目录。
- 两个获授权目录现在只用于指定路径的白名单校验。路径指纹、上传前检查、阶段限制和 E/F 确认不变。没有删除/移动已有视频或修改作品关联。
- PRD/design 已同步，覆盖 U9 B/E 原来的目录发现要求。原提示词和旧报告作为历史记录保留。
