# 平台与选题采集并行（2026-10-21）

## 已实现

- 每个平台独立进程、锁、Ego 工作区和页面；AI 层原本已使用独立 Codex thread，保持原样。
- “全部重新采集”并发启动未运行的平台，单平台按钮只禁用自身。定时器也按平台分发；同一天沿用原随机时间，重试和成功结果各自记录。
- 选题取材改用 topic-sources 锁，不再借用平台总锁。同轮选题仍顺序读其来源；本次并行对象是不同任务，不擅自无限并发几十个渠道。
- 启动时只恢复本平台未结束日志，不再把其他运行中平台判为中断。确认登录的读取/过期也按平台隔离。
- 全站页面预算仍为原配置，短暂竞争等待后写入，测试证明不丢计数且到限拒绝。
- 已运行的旧版整批进程保留，完成后才启动新的平台任务，防止同平台重复采集。选题无需等待它。

## 边界与已知问题

本轮使用进程/浏览器替身及 fixture 验收，没有新增真实账号采集或选用真实候选。用户先前启动的真实旧任务未中断；真实多平台同时跑完、明早自动触发结果仍未验收。并发速度受机器、网络、Codex 额度与平台登录条件影响，不承诺固定提速倍数。每个来源批次仍可能因页面限制失败，错误会保留。
