## 真实浏览器走查

使用 Ego 打开本地 HTML：作品入口点击「继续这条作品」→素材页点击「准备检查稿件」→发布检查点击「去补齐横版封面」→回到素材。两页作品标题及图文/未确认状态一致；检查并上传按钮禁用。HTML 无脚本、无接口调用，不会生成、确认或上传数据。这里只验证方案跳转，不冒充已实现的新导航。
