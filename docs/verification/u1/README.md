# U1 · 全站通用件与清理验收（2026-10-20）

本轮完成 U1，未进入 U2。U0 已标 ✅，原记录补上 83bf86a。

## 修改范围

- `src/ui/`：统一三种按钮、无边框状态标签、PageHeader；禁用按钮变淡且不可点击，鼠标悬停或键盘聚焦显示共享 ⓘ 原因浮层（同一时刻只有一个，也支持弹窗）。
- 八个页面只调整通用组件调用、展示样式与文字。导航组件未改；主操作和刷新在 1440×900 首屏可见。
- 去掉 LOCAL / 英文代号 / 口号、卡片编号和英文装饰元信息；发布审查进度、流程和规则说明移出页面。
- 测试记录在 UI 读取适配层过滤，覆盖初始读取和刷新；按名称“验收/测试”及显式 fixture 标记识别，并过滤相关作品、草稿、发布记录和回执。没有删除数据，也没有修改请求、接口、数据库、算法或配置。
- “已选定”“已送入选题”等完成状态改为文字标签；仍可切换的筛选项保留按钮。没有伪造服务就绪，上传与发布不可用时仍禁用。

## 说明文字与首屏起点

说明数以改前默认页面的**说明块**计：一块多句算 1，重复出现在三个平台的说明算 3；不计卡片编号、英文元信息、状态、测试记录或未打开弹窗中的说明。逐条清单见 [removed-inventory.json](removed-inventory.json)，原始说明和规则去向见 [removed-notes.md](removed-notes.md)。

起点以浏览器 CSS 像素计，从视口顶部到页头之后第一个内容区（数据健康、作品栏、选题概况、用途栏、文章来源、发布来源、读取状态或商单概况）的顶部。原始测量见 [before.json](before.json) 与 [after.json](after.json)。截图视口高度为 900，文件为整页截图，便于核对首屏以下内容。

## 验证结果

- 8 页 × 2 档 × 改前/改后，共 32 张页面截图；逐页检查首屏与整页，无横向溢出，主操作均在首屏。
- 旧 LOCAL、BRIEF、ASSET、HANDOFF、WRITE ONCE、READ ONLY、PUBLISHING DESK 等显示文字均已清除；跳转链接带 →。
- 商单详情打开、收件箱“查看待回复”筛选及翻页、禁用翻页键盘提示、发布上传鼠标提示均通过。[交互记录](interactions.json) · [禁用提示截图](disabled-help.png)
- 发布页示例中的验收草稿/成片不再显示；直接只读核对原接口仍返回 3 条发布记录、4 条含测试/验收名称的作品。过滤单测证明源数据不被改写，命中率结果和基线不重新计算。
- `npm run format`、`npm run check` 全绿：38 个测试文件、97 项测试（原 94 项 + 3 项展示过滤测试），其余既有业务检查全部通过；`npm run build` 通过。
- 检查中曾发现读取工具的 Node 检查需要显式 `.ts` 导入，已修复并全量重跑。浏览器翻页测试首次定位名不匹配，重新读取页面后使用正确名称通过；没有触发业务写入。

## 本轮边界

空模块收纳、详情默认选中、图表范围、过期数据展示及各页面主区域重排属于后续 U2–U6；本轮保留现有页面业务布局，不将 U1 误报为整轮改版完成。没有生成图片/文案、上传平台或真实发布。E/F 确认要求继续有效。
