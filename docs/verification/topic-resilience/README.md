## 实际根因

本机状态接口核对到最近一轮任务 `fbcb7fae-ebfe-4309-832d-d8457fcf6ce8`，北京时间 22:19 开始、22:36 结束。原始失败记录：X、智源社区、AI HOT 均超过单次页面读取上限，随后“本批未生成，未跳过启用渠道”。原实现要求所有网站成功，而且必须读到页面底部；无限滚动页面即使已经读到内容也会被整批丢弃。前端等待长请求，没有读取数据库里的运行状态。

## 已实现

- 单站登录、网络、验证、无相关信息或提取失败均记录原因，继续下一站；已完成来源逐个落库。
- 到达滚动上限时使用已读到、可核对的原文，并显示“部分读取”；不将其声称为完整页面。用户接管或浏览器执行状态不明确时保留停止边界。
- 优先本轮材料；本轮无新材料时允许已存启用渠道线索回退，明确说明和显示来源日期。无任何材料不调用生成模型。
- 目标仍为20个，材料不足可少量生成，保留来源引用、去重、FIRE与原子保存约束，不修改旧选择。
- 独立 Node 后台进程，持久化阶段、当前网站、逐站结果和进程身份；启动互斥、重复点击不重复运行、进程中断明确失败，不自动重试。复用现有表，无迁移和新增依赖。
- 候选上方显示状态卡、扫描线、耗时和可折叠失败清单；两秒只读取轻量任务接口，不重复调用AI或复盘计算；完成后自动取回候选。
- 每轮数据库自动备份，备份失败单独提示，不把已保存候选说成丢失。
