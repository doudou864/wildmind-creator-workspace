# 视频封面直接对话验收 · 2026-10-23

## 交付

- 视频封面左边只有原文提示词、技能单选、发送与对话历史；右边显示实际返回图片、原始尺寸和下载链接。移除关联作品/选题、风格、参考图表单与预设三图生成。
- 独立会话不创建作品。原文（包括首尾空格和换行）独立传给 Codex；完整技能正文/路径作为另一条输入。当前技能可清空或更换；本机两个配置目录实际发现94个技能。
- 图片按原尺寸保存，无自动裁剪/拉伸，素材可在发布准备复用。输入和技能自动留在本机浏览器，对话/图片保存数据库；刷新继续，进程中断保留已完成部分并明确提示，不自动重试。
- 原有作品对话和其他生图用途保持原有调用。数据库先通过在线备份，再用Drizzle增加两张独立会话表，旧表不改。无新增依赖。
