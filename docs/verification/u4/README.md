## 为什么发布第 6 天只画到 D4

作品 `55a8f603…` 发布于 10-14 02:20（上海时间）。数据库只存了 D3、D4 播放采样：D3 第一次 1,172（10-17 19:49），随后两次 1,179；D4 为 1,510（10-18 10:36）。当前是 10-20，日龄已到 D6，但 D5、D6 没有采集点；D1、D2 也没有。没有人为截短或补值。原始只读查询见 [采样证据](sampling-evidence.json)。

图表继续使用 dailySample 的每天第一次有效采样，D3 表格继续使用 firstSample；页头与总控台统一读取最新保存值 1,510。分别标“每日首次采样”和“最新累计播放”，保留算法与 API。
