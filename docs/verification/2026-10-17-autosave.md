# 自动保存输入回归

- typecheck、build、全部原有 check 脚本通过；新增 check-autosave 验证串行合并、失败原因、离开 flush 和不占 busy。
- ego 生图页隔离延迟请求：第一条保存暂停时，输入框 disabled=false、focused=true，角落显示“保存中”。继续输入后放行，实际请求为 POST“保存前”→ PATCH 同一 ID“保存期间继续输入”，没有重复创建。
- 截图：autosave-input.png。测试仅在浏览器拦截请求，没有向平台发布或伪造正式服务能力。
- 站内离开 flush 最新内容；隐藏/离开文档触发 flush，JSON 请求使用 keepalive。浏览器被强制终止、断电或超过浏览器 keepalive 配额不能保证网络完成，失败保留当前输入并显示原因。
