# design.md · 前端设计规范

风格：**工业仪器面板**。暖灰底、平面卡片、等宽数字、黑白为主、只用一个橙色做强调。
视觉参考：`docs/design-reference.webp`（总控台）。其他页面没有参考图时，沿用本文件的规则和组件。

## 1. 原则

1. **数据是主角**：大数字、方块、格子条承担信息，装饰越少越好。
2. **只有一个强调色**：橙色只用来标「需要注意」的东西。一屏里橙色越少，越有用。
3. **平面、硬朗**：不用渐变、大阴影、大圆角、毛玻璃；界面里不用 emoji，少用图标。
4. **只做桌面宽屏**：最小宽度 1440px，不做手机适配。

## 2. 颜色（只用这些）

| 变量 | 色值 | 用途 |
|---|---|---|
| `bg` | `#D9D7D3` | 页面背景 |
| `card` | `#EEECE8` | 卡片 |
| `line` | `#BDBBB7` | 卡片边框、按钮边框 |
| `line-soft` | `#CFCDC7` | 行分隔虚线、未点亮的方块和格子 |
| `ink` | `#1A1A1A` | 主文字、点亮的方块、选中态背景 |
| `ink-2` | `#7A7873` | 次要文字（小标签、说明） |
| `ink-3` | `#A3A19C` | 弱文字（坐标轴、`--`） |
| `accent` | `#FF5A1E` | 强调：当前导航、异常、待处理、达到命中阈值、最新一天 |
| `accent-dark` | `#C9400F` | 强调按钮的底边阴影 |

**橙色用在哪里**：当前导航页、健康条的抓取失败、待处理商单数量（大于 0 时）、`HOT` / `DROP` / `FIRE` 标签、倍数达到命中阈值的格子条、趋势图的最新一天、粉丝净减。除此之外一律不用。

## 3. 字体与数字

- 等宽：`"JetBrains Mono", "PingFang SC", monospace`，用于数字、时间、英文代号（`DY`、`00 · SOURCE`、`4 ITEMS`）。
- 正文：`"PingFang SC", -apple-system, sans-serif`，用于中文标题和内容。
- 所有数字开启 `tabular-nums`。

| 层级 | 字号 / 字重 | 示例 |
|---|---|---|
| 主数字 | 44px / 700 等宽 | `128,402` |
| 大数字 | 32px / 700 等宽 | `86,214`、商单 `02` |
| 指标值 | 20px / 600 等宽 | `46,210`、`31.4%` |
| 卡片标题 | 15px / 600 | `今日行动` |
| 正文 | 14px / 500 | 作品标题 |
| 小标签 | 12px / 400，`ink-2` | `D21 基线`、`视频 10-02` |
| 代号 / 表头 | 11px / 500 等宽，全大写，字距 0.08em，`ink-2` | `TITLE`、`4 ITEMS`、`SYNC` |

**数字格式**：千分位 `128,402`；百分比保留 1 位 `31.4%`；倍数保留 1 位：格子条前只写数字 `3.4`，文字说明里写 `3.4×`；空值显示 `--`；时间 `10:41`，昨天写 `-1D 10:38`；日期 `10-02`；顶栏日期 `2026-10-16 FRI`。

## 4. 布局

- 背景 `bg`，卡片间距 12px，卡片内边距 18px。
- 圆角：卡片 6px，按钮 4px，标签 2px。
- 卡片：`card` 底 + 1px `line` 边框，无阴影。
- 列表行之间用 1px 虚线 `line-soft` 分隔，行高约 56px。
- **总控台**：顶栏 → 通栏健康条 → 三栏（左 1/4：今日行动、商单、洞察与异常｜中 1/2：平台趋势、近期作品｜右 1/4：粉丝）。

## 5. 通用组件

| 组件 | 规则 |
|---|---|
| 卡片标题 | 左侧 `01` 编号（11px 等宽，`ink-2`）+ 标题；右侧放元信息（`4 ITEMS`、`LIST →`、`30D`） |
| 导航按钮 | 键帽样式：`card` 底、1px `line` 边框、`box-shadow: 0 2px 0 line`；当前页为 `accent` 底白字，阴影用 `accent-dark` |
| 小按钮 | `送进选题`、`重抓`：12px，1px 边框；`重抓` 用 `ink` 底白字 |
| 切换器 | `7D / 30D / 90D`、平台切换：小描边块，选中为 `ink` 底白字 |
| 标签 | 11px 等宽大写，`accent` 底白字：`HOT`（可能在爆）、`DROP`（下滑或限流）、`FIRE`（🔥 选题）；`EXPLORE`（探索位）用 `ink` 描边 |
| 状态点 | 健康条：◉ 成功（`ink`）、● 失败（`accent`）、○ 尚未抓取（`ink-3`） |
| 字母序号 | 今日行动的 `A B C D`：方框描边，等宽字 |
| 走势类型 | 用文字表示：爆发型 / 长尾型 / 昙花型 / 未命中 / 观察中 / 走势中，不用 emoji |
| 空状态 | 一行 `ink-2` 文字，例如「今天没有待办」 |

## 6. 图表（ECharts，统一主题放在 `src/ui/`）

- **方块柱状图**（平台趋势）：ECharts 象形柱图（pictorialBar），用重复的方块画出每一天。纵向最多 12 格，点亮 `ink`、未点亮 `line-soft`，最新一天用 `accent`。悬停显示当天的准确数值。横轴只标起、中、止三个日期。
- **细针图**（粉丝净增）：柱宽 2px，正值 `ink` 向上，负值 `accent` 向下。横轴标 `-30D` 和 `-1D`，图例写 `净增 / 净减`。
- **格子条**（近期作品的倍数）：用普通网页元素画，不用 ECharts。共 10 格，每格代表的倍数从配置读取（默认 0.35×）；达到命中阈值时点亮色用 `accent`，否则用 `ink`；未点亮用 `line-soft`。
- 所有图表都不画网格线和外框，坐标轴文字用 11px 等宽 `ink-3`。

## 7. 交互

- 悬停：行背景加深一点（`#E6E4DF`），不加阴影。
- 加载中：数字位置显示 `--`，不用转圈动画。
- 动画只用于切换数据时的淡入，时长 150ms 以内。

## 8. 禁止

渐变、彩色阴影、大于 6px 的圆角、第二个强调色、emoji、装饰性插画、居中的大段文字、为了填满版面而加的装饰元素。

## 9. 验收清单（每个页面完成后自查）

1. 用 ego 打开页面，在 1440px 和 1728px 两种宽度下截图，和参考图对照。
2. 颜色是否只用了第 2 节的变量？橙色是否只出现在第 2 节列出的地方？
3. 数字是否都是等宽字体，格式是否符合第 3 节？
4. 卡片、按钮、标签、图表是否复用了 `src/ui/` 里的组件？
5. 空值是否显示 `--`，空状态是否只有一行字？
