# 选题输入渠道

## Agent 读取规则

- 每次推荐前读取本文，只使用启用的渠道。
- 将线索提炼成 1–2 句选题方向，保留原始线索和可核对的来源链接；缺链接时如实说明。
- 每批候选数量、探索位数量、FIRE 开启门槛读取 parameters.yaml。
- 历史选题决定方向范围，历史实际表现决定 FIRE；不合成加权分数、不维护题材标签。
- FIRE 理由必须包含同类历史作品的 D21 倍数，有走势类型则一并注明。
- 探索位用于未做过、近期有热度证据的方向；没有证据时不能声称已经验证热度。
- 不使用小红书笔记灵感、YouTube 热门趋势灵感页。

## 渠道配置

下面的 YAML 是页面读取的配置。内置渠道只开关；外部渠道可增删。修改后刷新页面。当前前端只展示这些配置，不执行采集。

```yaml
channels:
  - id: search_keywords
    name: 抖音搜索关键词
    enabled: true
    kind: builtin
    type: 搜索词
    location: 抖音作品详情 · 流量分析
    focus: 观众主动搜索的需求
    frequency: 每天
    note: 用户通过哪些词找到了作品
  - id: followup_search
    name: 看完后常搜的词
    enabled: true
    kind: builtin
    type: 后续搜索
    location: 抖音作品详情 · 流量分析
    focus: 观众看完后还想知道什么
    frequency: 每天
    note: 延续已发布作品中的未解问题
  - id: valuable_messages
    name: 有价值的问题与观点
    enabled: true
    kind: builtin
    type: 评论与私信
    location: 互动收件箱 · 有价值的问题和观点
    focus: 高频问题、具体困惑和不同观点
    frequency: 每天
    note: 收件箱尚未接入，页面仅展示演示线索
```

## 外部渠道模板

在上面的 channels 列表中追加条目；id 必须唯一，kind 使用 external。填写名称、启用、类型、位置、关注什么、读取频率、备注。未填写前不默认接入任何外部来源。

示例字段（请替换为真实渠道后再启用）：

```text
id: 自定义唯一代号
name: 渠道名称
enabled: false
kind: external
type: 网站 / 创作者 / 社区
location: 可访问的完整来源地址
focus: 关注的问题
frequency: 每天 / 每周
note: 读取范围和补充说明
```
