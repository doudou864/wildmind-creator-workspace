# WILDMIND · 野生脑洞工作台

总控台与选题中心前端，依据 `docs/wildmind-creator-workspace-PRD-v1.7.md`、`docs/design.md` 和参考图实现。用户已批准先开发前端，因此当前不代表 PRD 第 1–5 步完整业务落地。

## 本地运行

环境：Node.js 22 LTS，npm。

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:3000 。只监听本机。

```sh
npm run typecheck
npm run build
npm start
```

生产构建使用 Next.js 内置 Webpack；当前环境的 Turbopack 生产构建在创建子进程端口时出错。没有新增打包器依赖。启动生产服务前先停止占用 3000 端口的开发服务。

## 当前可以使用

- 总控台：数据健康、今日行动、平台趋势、粉丝总数与净增、近期作品、商单概况、作品异常。
- 平台、账号指标、7 / 30 / 90 天、内容形式切换。
- 作品详情、采集状态弹窗、键盘关闭与焦点恢复。
- 演示 / 无数据视图；新平台空状态；采集失败、样本不足和缺失指标展示。
- 选题中心 `/topics`：20 个候选、3 个探索位、来源和 D21 推荐理由，支持状态/类型/渠道筛选及搜索。
- 选中、跳过、移回候选；首次选中的 FIRE 标记和理由定格，演示记录保存在当前浏览器，刷新与页面导航后恢复。
- 选题样本不足 / 无数据场景；存储损坏或写入失败会提示，不伪报保存成功。

默认是 **2026-10-17 的固定演示数据**，页面始终标注 DEMO，不会访问真实平台。商单数量按 PRD 第 5 步先为 0；互动收件箱未接入，需求主题为空。总控台和选题中心可以互相导航，其余板块禁用。重抓执行和真实 AI 生成按钮禁用。

## 配置与结构

- `config/platforms.yaml`：9 个平台、采集方式说明、复盘主指标、内容形式、可切换账号指标。
- `config/metrics.yaml`：本次前端使用的账号指标子集，并非完整采集指标字典。
- `config/parameters.yaml`：时间范围、倍数格子、命中阈值、样本门槛、异常阈值、调度说明，以及选题数量、探索位范围和 FIRE 开启门槛。
- `config/选题输入渠道.md`：Agent 读取规则、三个内置渠道及外部渠道模板；YAML 配置块由页面实际读取。
- `src/lib/config.ts`：每次页面请求读取 YAML，Zod 校验失败时明确报错。改配置后刷新页面即可。
- `src/lib/demo.ts`、`src/lib/topic-demo.ts`：独立演示夹具；不代表抓取、AI 推断或真实复盘结果。
- `src/ui/`：共享组件、设计变量、页面样式、ECharts 主题与图表。
- `docs/verification/`：两种宽度的截图、空状态截图与验收记录。

字体随项目本地提供，许可见 `public/fonts/OFL.txt`。不依赖外部字体服务。

## 选题演示记录

使用专用键 `wildmind:topic-demo:v1`，不保存真实账号数据。页面底部可确认重置本页演示；“无数据”仅是预览，不删除已选记录。每个候选第一次选中时记录 FIRE 与理由，移回再选不会改变首次定格。真实来源链接未接入时显示 `--`。
